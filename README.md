One newspaper page that sums up the world's news of Saturday 21 November 2026 in a single 1024×1024 image: Russia's largest barrage of the year on Ukraine, with two missiles down in Poland; the ICJ's genocide finding against Myanmar; the UK–EU post-Brexit deals; Friday's Wall Street rout in a labelled market band; and six briefs from Antalya to Junín. draw_page.py renders the page with Pillow from the day's verified reporting and bakes it as entry.png; main.py copies that image to /output/entry.png, byte-identical on every run.

## Run it

```sh
python3 draw_page.py   # rebuilds entry.png from the story data
python3 main.py        # writes /output/entry.png
```
